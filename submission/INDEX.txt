Built with Remotion; the source is in ../video/src/. To rebuild:

    cd ../video
    npm install
    npm run build

Two traps worth knowing if you do. Remotion's bundler needs TypeScript 5 —
TypeScript 7 dropped ts.sys, which its esbuild loader calls, and the failure
surfaces as an unrelated "Cannot read properties of undefined (reading
'readFile')" deep inside webpack. And "type": "module" in the video's
package.json breaks the bundler outright.
